Autocorrection

Les fautes les plus fréquentes, balayées

Apostrophes typographiques, capitalisation des marques, accents oubliés sur les noms propres et expressions courantes. Ce n’est pas du correcteur post-coup : c’est appliqué à la frappe.

  • chatgpt → ChatGPT
    ChatGPT m’a aidé sur…

    Oui, je viens.

    jusqu’à demainjusqu’ici

Touche magique ★

Un suffixe explicite pour les expansions longues

Pour vos snippets fréquents — formules de politesse, signatures, identifiants — la touche ★ déclenche l’expansion de manière non ambiguë. Aucun risque de collision avec la frappe normale.

  • ct★ → c’était
    ct★ génial→ c’était génial
  • pex★ → par exemple
    pex★ ce matin→ par exemple ce matin
  • np★ → Adrien Moyaux
    Cordialement, np★→ … Adrien Moyaux
  • dt★ → 07/05/2026
    Le dt★ à 14h→ Le 07/05/2026 à 14h

Vos propres hotstrings

Et ceux que vous tapez tous les jours.

Hotstrings personnels

Édités depuis le menu, stockés en TOML, rechargés à la volée.

Ajouter un raccourci en 5 secondes

  1. Sélectionnez le texte que vous voulez transformer en hotstring.
  2. Ouvrez le menu → Hotstrings perso.
  3. Donnez un trigger (ex : sig★).
  4. C’est en place, sans relancer le driver.

Hotstrings dynamiques

Calculés au moment du déclenchement — date du jour, IBAN, infos perso.

Préfixe @ pour les données vivantes

Certaines valeurs changent chaque jour (la date) ou ne doivent pas être codées en dur (numéro de téléphone, IBAN). Les hotstrings dynamiques lisent ces valeurs au moment de l’expansion.

  • @dt → 07/05/2026 Date du jour (FR)
  • @dtL → 7 mai 2026 Date du jour en lettres
  • @ph → 06 12 34 56 78 Téléphone configuré
  • @iban → FR76 1234 … IBAN configuré

Vos infos en un seul endroit

L’éditeur d’infos personnelles centralise nom, e-mail, téléphone, adresse, IBAN. Les hotstrings dynamiques s’en servent automatiquement.

★ — la touche signature

Une touche, deux comportements.

La touche ★ a deux modes : répéter la lettre précédente ou déclencher une expansion (hotstring). Les deux sont décidés au moment du déclenchement selon le contexte — sans configuration.

1. Répéteur de lettre

Si aucune abréviation ne correspond, ★ double simplement la lettre précédente. Plus de SFB sur les doublons.

  • l★ → ll elle
  • r★ → rr erreur
  • t★ → tt attendre
  • p★ → pp frappe
  • n★ → nn année

2. Déclencheur d’abréviations

Si la lettre précédente forme un trigger connu, ★ expanse à la place. Aucun risque de collision avec la frappe normale.

  • a★→ainsi
  • c★→c’est
  • ct★→c’était
  • dé★→déjà
  • ê★→être
  • eef★→en effet
  • f★→faire
  • m★→mais
  • pcq★→parce que
  • pê★→peut-être
  • pex★→par exemple
  • r★→rien

Ajoutez n’importe quel autre modèle

Une option « Ajouter un modèle personnalisé » accepte n’importe quel identifiant HuggingFace (pour MLX) ou tag Ollama. Exemple : mlx-community/Qwen2.5-3B-Instruct-4bit ou llama3.2:3b. Le modèle apparaît immédiatement dans la liste, et reste persisté entre les sessions.

Vous pouvez littéralement utiliser n’importe quel modèle publié sur HuggingFace au format MLX, ou n’importe quel modèle disponible dans la bibliothèque Ollama.

3. Choisissez (ou écrivez) votre profil de prompt

Quatre profils intégrés couvrent les usages courants — chacun avec un prompt système précis, rédigé pour fonctionner sur les petits modèles aussi bien que sur les gros.

Raw Continuation littérale

Aucune instruction injectée — le modèle reçoit juste le contexte brut {context} et continue. Idéal pour le code, les listes, les formats stricts.

Basic Profil par défaut

Instruction française minimale qui contraint le modèle à produire entre N et M mots, sans commentaires. Le compromis vitesse/qualité standard.

Advanced Correction + prédiction

Format à deux lignes : TAIL_CORRECTED (correction) puis NEXT_WORDS (prédiction). Bilingue FR/EN, accompagné d’exemples few-shot pour les petits modèles.

Batch Advanced N suggestions en 1 requête

Une seule requête réseau qui produit N continuations alternatives séparées par ===. Beaucoup plus économique qu’N requêtes séquentielles.

✎

Ou rédigez votre propre prompt

L’éditeur de prompts intégré (Menu IA → Profils → Ajouter) accepte n’importe quel prompt système avec les variables {context}, {min_words}, {max_words}. Imposez un ton, une langue, une longueur, des contraintes métier. Vos profils sont persistés et réutilisables.

Exemples d’usages : « Réponds toujours en québécois soutenu », « Génère du code TypeScript strict », « Termine ma phrase comme Hemingway ».

Gestes trackpad · macOS

Le clavier ne fait pas tout. Le trackpad non plus, seul.

Le driver intercepte les gestes bruts du trackpad (pas les événements de souris) et les associe à n’importe quelle action. Plus de zigzag main droite/clavier — vos doigts restent là où ils sont.

3 doigts Tap
Définition du mot

Pose 3 doigts sur un mot, sa définition apparaît instantanément. Plus naturel qu’un Cmd+Ctrl+D.

Tap 3 doigts = définition instantanée

Posez 3 doigts sur un mot dans n’importe quel texte (Safari, Mail, Pages, Slack, VS Code…) : sa définition apparaît dans une popover. C’est le geste le plus utilisé d’Ergopti+ selon nos métriques internes — plus rapide qu’ouvrir un onglet vers un dictionnaire.

Une trentaine d’actions sont fournies : navigation entre fenêtres, contrôle du volume, mots/lignes/paragraphes, copier/coller, captures d’écran, raccourcis applicatifs… Vous pouvez aussi pointer vers un script Lua pour des actions sur-mesure.

Tout sous votre contrôle

Absolument tout est personnalisable. Et désactivable.

Aucune fonctionnalité n’est imposée. Chaque expansion, chaque tap-hold, chaque geste, chaque tooltip, chaque délai, chaque couleur peut être modifié, désactivé, réinitialisé. Vous décidez. Le menu est là pour vous mettre à l’aise — jamais pour vous piéger.

1

Activez fonction par fonction

Chaque catégorie de hotstrings, chaque tap-hold, chaque geste trackpad a sa case à cocher. Démarrez avec 3 fonctions, ajoutez-en 2 le mois suivant, jamais d’obligation.

2

Réglez les valeurs

Délais, couleurs, modèle d’IA, raccourcis, prompt, longueur de contexte, apps ignorées, chemins de fichiers — chaque paramètre est exposé dans le menu, réversible d’un clic.

3

Réécrivez les hotstrings

Un trigger livré ne vous convient pas ? Modifiez la valeur dans le TOML, le driver recharge tout seul. Vous voulez en ajouter ? Le menu écrit le fichier pour vous.

⚠ Spécifique à la disposition Ergopti

Exclusivités Ergopti.

Tout ce qui précède fonctionne sur n’importe quelle disposition (AZERTY, QWERTY, Bépo…). Les fonctionnalités ci-dessous, en revanche, exploitent les positions exactes des touches d’Ergopti — virgule sous l’index, ★ à la place du J, voyelles accentuées dédiées. Sur un autre layout, elles n’auraient aucun sens.

C’est l’autre moitié du gain. Si vous adoptez Ergopti, vous récupérez tout cela gratuitement.

    c-éà-l → ciel
  • àé → éi
    ant-àé-r → antérieur
  • êe → œ
    s-êe-ur → sœur

Hotstrings via touche magique ★

Doublons et SFBs neutralisés via ★

La touche ★ a deux comportements : répéter la dernière lettre, ou déclencher une expansion. Quelques expansions exclusivement Ergopti tirent profit de la position de ★ sous l’index gauche.

  • à★ → bu
    dé-à★-t → début
  • àu → ub
    t-àu-e → tube
  • ★ê → u
    con★ê → connubat★ê → battu

Des touches qui font le travail de plusieurs

Ergopti+ tire profit de séquences statistiquement absentes du français pour placer des raccourcis qui ne créent jamais de faux positifs.

La touche , + voyelle remplace le j

Le j minuscule devient la touche magique ★. À sa place, la virgule prend le relais : la séquence , + voyelle est inexistante en français (, est toujours suivi d’un espace), donc on la détourne pour produire un j.

,a → ja
,e → je
,i → ji
,o → jo
,u → ju
,é → jé
,' → j’

La touche , + consonne pour un layout 1DFH

Les lettres rares (z, k, q, ç) sont accessibles via la virgule, donc plus à 1u du repos des doigts. Le mot où aussi — bonus, en deux frappes au lieu de trois.

,è → z Lettre Z
,y → k Lettre K
,s → q Lettre Q
,c → ç Cédille
,x → où Mot complet

Q + voyelle = QU automatique

En français, q + voyelle implique presque toujours un u caché. Tapez qe, qi, qa — le u s’insère seul.

qe→que qoi→quoi

Touche ù = mot où

La touche ù n’est utilisée que pour le mot où. Autant en faire le raccourci direct.

AltGr+W→où

Touche ê = circonflexe en une frappe

Le bigramme le plus fréquent du circonflexe est ◌̂ + e. Une touche dédiée évite l’aller-retour. Pour â, î, ô, û : êa, êi, êo, êu.

ê→ê êa→â

Apostrophe typographique automatique

Tapez ' dans du texte, vous écrivez ’. Tapez-la dans du code, elle reste droite. Aucun réglage à faire.

l'ami→l’ami

BackSpace à portée de pouce

La touche la plus utilisée du clavier (BackSpace) est dupliquée sur "LAlt", juste sous la main. Shift + cette touche envoie Delete. AltGr + cette touche envoie Ctrl+BackSpace (efface un mot entier).

Roulement nt' pour l’anglais

nt' devient n’t — la combinaison parfaite pour don’t, won’t, can’t. Majeur → annulaire → auriculaire au lieu de l’inverse, beaucoup plus confortable.

Suffixes en À — tapez 2, écrivez 5

La touche à n’est suivie que d’un espace ou d’une ponctuation en français (seuls à, là, déjà contiennent à). On en a profité pour caler dessus les suffixes les plus fréquents. Le suffixe -ement coûte normalement 5 frappes : il en coûte 2.

às → ement
àt → ation
àn → ment
àr → eur
àl → elle
àp → isme

Symboles de programmation, en roulements confortables

Les combinaisons inconfortables (=>, !=, :=, </, =""…) sont remappées en roulements vers l’intérieur, sur la home-row d’Ergopti. Ces emplacements précis n’existent que sur cette disposition.

#! → := Affectation (Go, Pascal)
!# → != Différent de
<@ → </ Fermeture HTML/JSX
<% → <= Inférieur ou égal
$= → => Fat arrow (JS)
+? → -> Flèche (Rust, types)
\" → /* Début commentaire bloc
"\ → */ Fin commentaire bloc
(# → (" Ouverture string en argument
[) → ="" Attribut HTML vide

Compatibilité dispositions

AZERTY, QWERTY, Bépo, Dvorak — tout fonctionne.

Ergopti+ est pensé pour la disposition Ergopti, mais le driver agit sur le texte qui sort de votre clavier — pas sur la touche que vous appuyez. Aucun changement de layout n’est nécessaire.

Hotstrings et autocorrection

Tout fonctionne quel que soit votre layout, parce qu’ils opèrent sur le texte produit. Vos expansions ct★, pex★, chatgpt… déclencheront en AZERTY, QWERTY ou Bépo.

Tap-holds, CapsWord, layer navigation

Ces fonctions agissent sur le code physique de la touche (scancode), donc indépendantes du layout actif côté OS. Elles fonctionnent à l’identique sur tous les claviers.

Gestes trackpad et IA

Les gestes trackpad sont des événements multi-touch bruts : aucune dépendance clavier. L’IA prédit du texte, peu importe sur quelle touche vous l’avez tapé.

Notre recommandation : Ergopti + Ergopti+ est la meilleure combinaison (la disposition tire profit des roulements et de la touche magique). Mais si vous restez sur votre layout actuel, vous récupérez quand même 70 % du gain.
